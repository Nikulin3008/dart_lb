# Vacancy Registry

Консольна програма для ЛР1. Структуру даних побудовано на записах (Records) замість класів відповідно до вимог лабораторної роботи.

Лабораторна робота №2:
Архітектуру проєкту повністю перероблено на об'єктно-орієнтовану модель. Замість базових записів (Records) тепер використовуються строгі незмінні класи-сутності з іменованими та фабричними конструкторами (кешування). До логіки додано запечатані класи (sealed class) для ієрархії типів, домішки (mixin) для спільної валідації, узагальнене сховище даних (generics), а також реалізовано методи розширення (extension) та зіставлення зі зразком з охоронцем (pattern matching).
